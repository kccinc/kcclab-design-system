# Colors

`packages/ui/src/styles/tokens.css`

 `--ds-color-*` CSS 커스텀 프로퍼티로 정의되어 있습니다.<br/>
소비 프로젝트는 `:root`에서 이 변수들을 오버라이드해서 리테마할 수 있으며, 컴포넌트 코드에서는 절대 hex 값을 하드코딩하면 안 됩니다.

export const Swatch = ({ name, hex }) => (
  <div style={{ display: "flex", alignItems: "center", gap: 12, marginBottom: 4 }}>
    <div
      style={{
        width: 48,
        height: 48,
        borderRadius: 8,
        background: hex,
        border: "1px solid rgba(0,0,0,0.08)",
        flexShrink: 0,
      }}
    />
    <div style={{ fontFamily: "monospace", fontSize: 13, lineHeight: 1.4 }}>
      <div>{name}</div>
      <div style={{ color: "#6b7684" }}>{hex}</div>
    </div>
  </div>
);

export const Grid = ({ children }) => (
  <div
    style={{
      display: "grid",
      gridTemplateColumns: "repeat(auto-fill, minmax(160px, 1fr))",
      gap: 12,
      marginBottom: 8,
    }}
  >
    {children}
  </div>
);

export const RoleGroup = ({ roleName, role }) => (
  <div style={{ marginBottom: 24 }}>
    <h4 style={{ textTransform: "capitalize" }}>{roleName}</h4>
    <Grid>
      {Object.entries(role).map(([step, hex]) => (
        <Swatch key={step} name={`${roleName}-${step.toLowerCase()}`} hex={hex} />
      ))}
    </Grid>
  </div>
);

## 1. Semantic Colors

컴포넌트의 주요 액션/상태를 나타내는 색상입니다. 리브랜딩·테마 변경 시 이 값들만
바꾸면 전체 컴포넌트에 반영됩니다.

<RoleGroup roleName="primary" role={colors.action.primary} />
<RoleGroup roleName="secondary" role={colors.action.secondary} />
<RoleGroup roleName="success" role={colors.action.success} />
<RoleGroup roleName="danger" role={colors.action.danger} />
<RoleGroup roleName="warning" role={colors.action.warning} />
<RoleGroup roleName="info" role={colors.action.info} />

## 2. Text Colors

`colors.grey.*`를 직접 쓰지 말고, "본문인지 보조설명인지 비활성인지" 역할 이름으로 사용하세요.

<Grid>
  <Swatch name="text-primary" hex={colors.text.primary} />
  <Swatch name="text-secondary" hex={colors.text.secondary} />
  <Swatch name="text-tertiary" hex={colors.text.tertiary} />
  <Swatch name="text-disabled" hex={colors.text.disabled} />
  <Swatch name="text-placeholder" hex={colors.text.placeholder} />
  <Swatch name="text-inverse" hex={colors.text.inverse} />
</Grid>

## 3. Border Colors

인풋, 카드, 구분선 전용 색상입니다. text/background와 분리해서 "이 테두리가 어떤
쓰임인지" 이름만 보고 알 수 있게 합니다.

<Grid>
  <Swatch name="border-default" hex={colors.border.DEFAULT} />
  <Swatch name="border-strong" hex={colors.border.strong} />
  <Swatch name="border-primary" hex={colors.border.primary} />
  <Swatch name="border-danger" hex={colors.border.danger} />
</Grid>

## 4. Background

실제 팔레트 대신 "용도"로 이름 붙인 배경 토큰입니다. 다크모드 전환 시에도
클래스명을 바꾸지 않아도 되게 해줍니다.

<Grid>
  <Swatch name="background" hex={colors.semantic.background} />
  <Swatch name="grey-background" hex={colors.semantic.greyBackground} />
  <Swatch name="layered-background" hex={colors.semantic.layeredBackground} />
  <Swatch name="floated-background" hex={colors.semantic.floatedBackground} />
</Grid>

# Shadow (Elevation)

`packages/ui/src/styles/tokens.css`

`--ds-shadow-elevation-*`로 정의되어 있으며`shadow-[var(--ds-shadow-elevation-1)]` 형태로 사용하세요. <br/>
숫자가 클수록 화면 위로 더 떠 보이는 요소를 의미하므로 일관되게 사용하세요.<br/>

`tailwind.tokens.js`의 매핑 참고: 1 = 카드·리스트 아이템, 2 = 드롭다운·팝오버, 3 = 모달·바텀시트,
4 = 토스트·최상위 오버레이
